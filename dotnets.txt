### Deploy-Self-Service Template
**Purpose**: Streamlined terminal-only workspace for quick tasks

**Best For**: Infrastructure management, deployment tasks, CLI operations, quick edits

**Includes**:
- Terminal access only (no IDE)
- Claude Read-Only access
- Automatic dotfiles configuration
- Fixed resources (1 CPU, 2GB RAM, 1GB Storage)

**Resource Allocation**: Fixed minimal resources for cost-effective operations

<details>
<summary><strong>Template Comparison Matrix</strong></summary>

| Feature | RDX-General | RDX-Analysis | Deploy-Self-Service |
|---------|--------------|--------------|---------------------|
| **IDEs Supported** | VS Code, IntelliJ | VS Code, IntelliJ | Terminal only |
| **Languages** | Python, Java, Go, .NET | Python, Java, Go, .NET | All (via CLI) |
| **Specialized Tools** | General development | Conda, data science libraries | Claude Read-Only |
| **Resource Flexibility** | Fully configurable | Optimized for analytics | Fixed minimal |
| **Best For** | Multi-language development | Data science/analytics | Quick CLI tasks |
| **Workspace Size** | 20GB+ (configurable) | 40GB+ (recommended) | 1GB (fixed) |
</details>

## How to Choose the Right Template

### Decision Flow

```mermaid
graph TD
    A[Start Workspace Creation] --> B{What is your primary task?}
    B --> C[General Software Development]
    B --> D[Data Analysis / Data Science]
    B --> E[Quick CLI / Deployment Tasks]
    
    C --> F[Choose RDX-General]
    D --> G[Choose RDX-Analysis]
    E --> H[Choose Deploy-Self-Service]
    
    F --> I[Configure resources as needed]
    G --> J[Use analytics-optimized settings]
    H --> K[Fixed resources - ready to go]
```

### Selection Guidelines

<details>
summary><strong>When to Use Each Template</strong></summary>

**Choose RDX-General if you:**
- Develop applications in multiple programming languages
- Need full IDE support (VS Code or IntelliJ)
- Work on general software engineering tasks
- Collaborate with teams using different tech stacks
- Need customizable resource allocation

**Choose RDX-Analysis if you:**
- Primarily work with data analysis or data science
- Use Jupyter notebooks extensively
- Need Conda for environment management
- Work with large datasets
- Perform statistical modeling or machine learning

**Choose Deploy-Self-Service if you:**
- Need quick terminal access for deployment tasks
- Are managing infrastructure or configurations
- Want minimal resource usage for cost savings
- Perform CLI operations without IDE overhead
- Need Claude Read-Only access for assistance
</details>

## Template Parameters and Configuration

### Common Parameters (All Templates)

| Parameter | Description | Type | Required |
|-----------|-------------|------|----------|
| **workspace_name** | Name for your workspace | Text | Yes |
| **tenant** | Team/tenant selection (from entitlements) | Dropdown | Yes |
| **cpu** | CPU cores allocation | Slider | Yes |
| **memory** | Memory allocation (GB) | Slider | Yes |
| **gitlab_token** | GitLab personal access token | Secret | Yes |
| **gitlab_repo** | Optional GitLab repository URL | Text | No |
| **dotfile_repo** | Optional dotfiles repository URL | Text | No |
