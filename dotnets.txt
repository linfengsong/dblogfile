## 4. How to Use Guided Architect Mode

### 4.1 Effective Interaction Patterns

**Instead of asking Claude to write code, ask for understanding:**

| Instead Of... | Try This... |
|---------------|-------------|
| "Write a function to process user data" | "Explain the patterns we should use for user data processing" |
| "Fix this bug" | "Help me understand what might be causing this issue" |
| "Implement feature X" | "What architectural approach should we take for feature X?" |
| "Optimize this query" | "Review this query and suggest optimization strategies" |

"Claude, please review this Python function for:

- Questions to answer before deciding

### 4.3 Understanding Rejection Messages

When Claude cannot access a repository or tool, you'll receive **educational messages**:

```plaintext
ACCESS DENIED: Repository Governance

The repository 'team/restricted-project' is not currently authorized 
for AI analysis in this workspace.

Why this matters:
• Intellectual Property Protection: This ensures proprietary algorithms 
  and business logic remain within controlled environments
• Compliance Requirements: Certain codebases have regulatory constraints 
  on AI processing
• Team Governance: Your architect team defines which repositories are 
  AI-accessible based on security classifications

What you can do:
1. Request repository authorization through your team lead
2. Work with the code locally without AI assistance  
3. Ask about architectural patterns that might apply (without accessing 
   the specific code)

Learn more about our governance approach in /home/coder/CLAUDE.md
```
