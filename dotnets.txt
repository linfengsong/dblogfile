### Connecting via JetBrains Gateway

1. **Ensure IntelliJ is installed locally** with JetBrains Gateway
2. **From RDX portal**, click "Connect" and select "IntelliJ"
3. **Copy the connection parameters** or use the direct link
4. **JetBrains Gateway will automatically**:
   - Detect the remote IntelliJ installation
   - Establish a secure connection
   - Launch the remote IDE interface

### Workspace Configuration for IntelliJ

When you select IntelliJ during workspace creation:

1. **Automatic resource allocation**: Workspace receives minimum 10GB VM, 8GB RAM
2. **IntelliJ binary provisioning**: 1.7GB IDE package downloaded during startup
3. **Auto-registration**: Remote IntelliJ automatically registers with JetBrains Gateway
4. **Installation location**: `/home/coder/.cache/JetBrains/RemoteDev/dist/IU-{build_number}`

<details>
summary><strong>Managing IntelliJ Installation</strong></summary>

- **Adding IntelliJ later**: Edit workspace settings and add "intellij" to `selected_tools`
- **Removing IntelliJ**: Remove "intellij" from `selected_tools` to free up resources
- **Storage cleanup**: Uninstallation automatically removes the 1.7GB binary
- **Version updates**: Handled automatically by RDX operations team
</details>

## IDE Version Management

### Evergreen Updates

RDX provides automatic IDE updates without workspace downtime:

<details>
<summary><strong>How Updates Work</strong></summary>

1. **New IDE versions** are built into the init-container image via CI/CD pipeline
2. **Existing workspaces** continue operating with their current version
3. **New workspaces** automatically receive the latest IDE version
4. **No user action required** for updates
5. **Version rollback** is possible if issues are detected

```plaintext
Update Timeline Example:
Day 1: IntelliJ 2025.2.6.1 is current
Day 15: Operations team releases IntelliJ 2025.2.7.0
Day 15+: New workspaces get 2025.2.7.0
Day 15+: Existing workspaces keep 2025.2.6.1 until restart
```
</details>

### Version Compatibility

| Component | Version Management | User Impact |
|-----------|-------------------|-------------|
| **VSCode Server** | Automatic updates | No action required |
| **IntelliJ** | Automatic updates | No action required |
| **Extensions/Plugins** | User-managed | Install/update as needed |
| **Development Tools** | Template-defined | Updated with template changes |
