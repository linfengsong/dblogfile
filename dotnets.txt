**`dotnet_win_runner_tag`:** This input has been deprecated in `build.yml`. For backward compatibility, it is still used to determine .NET builds using the Windows build when set up, but the value of this input is ignored when setting job `runner_tag`.

**`dotnet_build_runner`:** Add an additional option value "windows" to `build.yml`. Existing options of `windows_dotnet6` and `windows_dotnet8` have been deprecated in `build.yml`. Only pass `windows_dotnet6` to `dotnet.yml` for all `windows_dotnet6`, `windows_dotnet8` and `windows`.
