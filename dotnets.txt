## 9. Security and Compliance

### 9.1 Security Architecture

Guided Architect Mode implements **defense-in-depth**:

| Layer | Protection | Implementation |
|-------|------------|----------------|
| **Physical** | Filesystem jail | Path confinement to `/home/coder` |
| **Repository** | Smart allow/deny | Regex pattern matching on Git URLs |
| **Tool** | Runtime enforcement | Managed settings JSON |
| **Credential** | Token redaction | `glpat-*` pattern scrubbing |
| **Financial** | Hard quotas | LiteLLM virtual keys with limits |
| **Audit** | Complete logging | All tool calls with context |

### 9.2 Compliance Assurance

**Automated Governance**: Policies enforced at infrastructure layer ensure consistent compliance across all users.

**Audit Trail**: Every access decision is logged with:
- Timestamp and user identity
- Target repository and path
- Access decision (ALLOW/DENY)
- Pattern matched (if allowed)
- Cache status (hit/miss)

**Regular Reviews**:
- Monthly security posture reviews
- Quarterly access pattern audits  
- Annual compliance certification updates

### 9.3 Data Protection

**What's Protected**:
- Source code IP through repository access control
- Credentials through automatic redaction
- Financial data through quota enforcement
- User privacy through minimal data collection

**What's Logged**:
- Access decisions and patterns
- Budget consumption metrics
- Tool usage statistics
- Educational interaction patterns

**Retention Policy**:
- Security logs: 90 days
- Budget logs: 12 months (aggregated)
- Access patterns: 30 days (detailed), 12 months (aggregated)
